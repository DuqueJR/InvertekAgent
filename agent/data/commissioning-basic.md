## Keypad keys (Section 5.1, p.16)

- NAVIGATE: Used to display real-time information, to access and exit parameter edit mode and to store parameter changes.
- UP: Used to increase speed in real-time mode or to increase parameter values in parameter edit mode.
- DOWN: Used to decrease speed in real-time mode or to decrease parameter values in parameter edit mode.
- RESET / STOP: Used to reset a tripped drive. When in Keypad mode is used to Stop a running drive.
- START: When in keypad mode, used to Start a stopped drive or to reverse the direction of rotation if bi-directional keypad mode is enabled.

## Operating displays (Section 5.2, p.16)

- "StoP" = Drive Stopped / Disabled.
- "H 50.0" (example) = Drive is enabled / running, display shows the output frequency (Hz).
- "A 2.3" (example) = Press the Navigate key for < 1 second; the display will show the motor current (Amps).
- "P 1.50" (example) = Press the Navigate key for < 1 second; the display will show the motor power (kW).
- "1500" (example) = If P-10 > 0, pressing the Navigate key for < 1 second will display the motor speed (RPM).
- "FirE" = Drive is in fire mode and can't be reset until fire mode is deactivated.

## Changing parameters (Section 5.3, p.16)

1. Press and hold the Navigate key > 2 seconds.
2. Use the up and down keys to select the required parameter.
3. Press the Navigate key for < 1 second.
4. Adjust the value using the Up and Down keys.
5. Press for < 1 second to return to the parameter menu.
6. Press for > 2 seconds to return to the operating display.

## Read Only Parameter access (Section 5.4, p.17)

1. Press and hold the Navigate key > 2 seconds.
2. Use the up and down keys to select P-00.
3. Press the Navigate key for < 1 second.
4. Use the up and down keys to select the required Read Only parameter.
5. Press the Navigate key for < 1 second to display the value.
6. Press and hold the Navigate key > 2 seconds to return to the operating display.
