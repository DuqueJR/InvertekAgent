## Overview

The Optidrive E3 (ODE-3) is an AC Variable Speed Drive. The IP20 range covers 0.37kW – 37kW / 0.5HP – 50HP, 110 – 480V Single and 3 Phase Input (cover, p.1). This knowledge base's primary source, the IP20 User Guide Revision 1.05 (document 82-E3I20-IN), states: "This User Guide is for use with version 3.11 Firmware" (p.3). IP66 Indoor and IP66 Outdoor (switched) variants exist and have their own user guides; variant-specific content in this KB is labelled accordingly.

## Identifying the drive by model number (Section 2.1, p.7)

Each drive can be identified by its model number, as shown on the shipping label and the drive nameplate. The model number includes the drive and any options. Example format: ODE - 3 - 1 2 0021 - 1 F 1 2, decoded as:

- Product Family: ODE
- Generation: 3
- Frame Size: first digit (1–5)
- Input Voltage: 1 = 110 – 115, 2 = 200 – 240, 4 = 380 – 480
- Output Current x 10: four digits (e.g. 0021 = 2.1A)
- No. Of Input Phases: 1 or 3
- Filter Type: 0 = No Filter, F = Internal EMC Filter
- Dynamic Brake Transistor: 1 = Not Fitted, 4 = Internal Transistor
- IP Rating: 2 = IP20

## Warranty (General Information, p.3)

All Invertek Optidrive units carry a 2 year warranty against manufacturing defects from the date of manufacture. The local distributor may offer different terms and conditions at their discretion, and in all cases concerning warranty, the local distributor should be contacted first.
